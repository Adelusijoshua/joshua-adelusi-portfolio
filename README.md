## 📌 Overview
 
This is my personal portfolio website, built to showcase my work as a Data Analyst — covering Power BI dashboards, statistical analysis with SPSS, SQL, and Excel projects, plus a web development project. The site is a single-page, fully responsive experience with custom animations, a typing effect, live stats, and a project showcase, built entirely with vanilla HTML, CSS, and JavaScript — no frameworks required.
 
---
 
## ✨ Features
 
- **Custom animated cursor** — a smooth trailing ring that reacts and enlarges over interactive elements (links, buttons, project/cert cards)
- **Dynamic greeting** — updates based on time of day (morning/afternoon/evening) alongside a live clock
- **Typing effect** — hero role line cycles through multiple taglines with a realistic type/delete animation
- **Floating particle background** — subtle animated particles behind the hero section
- **Scroll-reveal animations** — sections and cards fade/slide into view as you scroll, using `IntersectionObserver`
- **Animated skill bars** — skill proficiency bars fill in when scrolled into view
- **Animated stat counters** — hero stats (projects, certifications, years) count up on scroll
- **Active nav highlighting** — nav links highlight automatically based on which section is in view
- **Scroll-aware navbar** — background opacity changes on scroll
- **Smooth anchor scrolling** — all in-page links scroll smoothly to their target section
- **Contact form feedback** — button shows a success state on submit (front-end only, no backend wired up)
- **Fully responsive** — built mobile-first friendly with a clean single-page layout

## 🚀 Getting Started
 
This is a static site with no build tools or dependencies required.
 
1. Clone this repository
2. Open `index.html` directly in a browser, **or** serve it locally:
```bash
   # Using Python
   python -m http.server 8000
 
   # Using Node (npx)
   npx serve .
```
3. Visit `http://localhost:8000`
The live version is deployed on **Netlify**: [joshuaadelusi.netlify.app](https://joshuaadelusi.netlify.app/)
